> An Eight Week Course Outline

## Course Summary

Vibe Engineering with AI Coding Agents is a project-based learning journey designed to help learners move from casual AI-assisted coding into disciplined, production-ready software engineering with AI tools. The course is structured around a clear progression:

- Vibe Coding
- Vibe Engineering
- Agentic Engineering

Instead of rushing through tools in a single session, this program gives each phase enough time to build real fluency, practical judgment, and hands-on experience across multiple projects.

---

## Format

- Eight weeks total
- Two instructional days per week
- One weekly hands-on build session
- A strong emphasis on practical project work

## Approach

This course follows a project-based path through:

- Vibe coding
- Vibe engineering
- Agentic engineering

## Core Tools

The course explores a modern ecosystem of AI coding tools, including:

- Claude Code

This program is designed for:

- Beginners who want to understand modern AI-assisted development

The course culminates in a real-time trading workstation built and operated by a coordinated team of AI agents.

# Course Overview

Vibe Engineering with AI Coding Agents takes the core ideas of agentic software development and gives them room to breathe across a full two-month learning arc. Instead of rushing through tools in a single sitting, each stage gets dedicated time: more practice with every tool, more variations on every project, and full weeks set aside for topics that a faster course would otherwise compress into a single afternoon.

The course follows a simple three-part arc. Learners begin with vibe coding, move into the more disciplined practice of vibe engineering, and finish with agentic engineering at an expert level. Each stage spans two to three weeks rather than a handful of days, with an added capstone week and a closing session on career paths and monetization.

## Structure at a Glance

### Month One: Foundations and Vibe Coding (Weeks 1 to 4)

- Mental models
- Prompt and context engineering
- Hands-on fluency with IDE-based agents such as Cursor, Copilot, Codex, and Antigravity

### Month Two: Vibe Engineering and Agentic Mastery (Weeks 5 to 8)

- Professional CLI workflows with Claude Code
- Multi-agent orchestration
- Sandboxing
- Full capstone build

## Weekly Rhythm

- Day 1: Concept lecture covering mental models, mechanics, and live demonstrations
- Day 2: Hands-on workshop to build, extend, or debug a real project
- Optional weekend session: Self-paced project work with prompts and checkpoints for asynchronous learners

# Month One

## Foundations and Vibe Coding

---

## WEEK 1

# Welcome to the Agentic Landscape

_Building the mental models everything else relies on_

> There is no project this week. The focus is purely conceptual, so later weeks move faster and with less confusion.

### Day 1: Orientation and the Eight Levels of AI Adoption

- A roadmap of how vibe coding, vibe engineering, and agentic engineering relate to one another
- The origin of vibe coding and how it grew into a professional discipline
- The eight levels of AI adoption, from basic prompting through autonomous multi-agent systems
- The three surfaces for AI coding tools: IDEs, plugins, and CLIs

### Day 2: How Large Language Models Actually Work

- Tokens, context windows, and memory explained from the ground up
- Why agent output varies from run to run, and how to design around that variability
- Hands-on exercise: generate a working app from a single prompt to feel the unpredictability firsthand

---

## WEEK 2

# Prompt and Context Engineering

_Giving agents the information they need to succeed_

> Project 1 begins: a personal website featuring an AI digital twin.

### Day 1: Context Engineering Fundamentals

- Writing effective prompts: specificity, constraints, and breaking work into small testable steps
- Introducing AGENTS.md and CLAUDE.md as project-level instructions an agent reads first
- Cross-checking agent answers across models to catch mistakes early

### Day 2: Workshop — Building Your AI Digital Twin

- Scaffold a personal website project with a clear AGENTS.md file
- Iterate with an agent through cycles of planning, generation, and feedback
- Review common failure modes and how targeted feedback resolves them

---

## WEEK 3

# Cursor and YOLO Mode

_Working quickly inside an AI-native IDE_

> Project 2: a Kanban-style project management app with drag-and-drop.

### Day 1: Cursor in Depth

- Cursor settings: autorun versus YOLO mode, and sandboxed versus unsandboxed execution
- Using planning mode and iterative feedback loops to steer an agent toward a working build

### Day 2: Workshop — Build the Kanban App

- Build a complete drag-and-drop Kanban app from scratch using Cursor in YOLO mode
- Debug and refine the codebase using specific, targeted feedback to the agent

---

## WEEK 4

# Copilot, Codex, and Antigravity

_Comparing agents across IDEs and providers_

> Project 3: a commercial-grade MVP, built end-to-end with the agent of your choice.

### Day 1: Touring the Alternatives

- GitHub Copilot's agent mode compared with Cursor's workflow
- OpenAI Codex for autonomous task execution
- Google Antigravity: rules, workflows, and parallel agent tasks

### Day 2: Workshop — Ship a Commercial MVP

- Choose a tool and scope a real MVP idea with a clear specification
- Build, test, and polish the MVP end-to-end as a portfolio piece
- A Month One retrospective comparing strengths and weaknesses across all four tools

_Extending what an agent can reach and do_

## WEEK 7

_Moving from a single agent to a coordinated team_

- Agent swarms and orchestration patterns, including Claude Agent Teams and Gas Town

# How to Fork This Git Repo

Forking a repository creates your own copy of the project under your GitHub account, so you can make changes without affecting the original repository.

## Option 1: Fork Using the GitHub Website

1. Open the repository page in GitHub.
2. Click the Fork button in the top-right corner.
3. Choose your GitHub account or an organization you belong to.
4. Wait for GitHub to create your fork.
5. Once the fork is ready, open the forked repository.

## Option 2: Clone Your Fork Locally

```bash
git clone https://github.com/MuhammadUzair1/Vibe-Engineering-SMIT.git
```

Replace:

- YOUR_USERNAME with your GitHub username
- REPO_NAME with the repository name

## Keep Your Fork Updated

If you want to sync your fork with the original repository later, add the original repository as an upstream remote:

```bash
git remote add upstream https://github.com/MuhammadUzair1/Vibe-Engineering-SMIT.git
```

Then fetch and merge updates:

```bash
git fetch upstream
git checkout main
git merge upstream/main
```

## Push Your Changes

After making changes locally:

```bash
git add .
git commit -m "Add my updates"
git push origin main
```

## Create a Pull Request

If you want to contribute back to the original repository:

1. Push your branch to your fork
2. Open the fork on GitHub
3. Click Compare & pull request
4. Submit the PR with a clear description
